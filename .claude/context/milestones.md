# Status

What is built today, and what is not.

**Built:** the local Docker stack, the seed, validated config, structured logging, `/health`, guarded text to SQL, the embedding pipeline and Elasticsearch index, the query router, hybrid retrieval with RRF, cited answers with a citation guard, `POST /chat` over SSE, the Angular chat UI with property cards, the voice agent and the eval harness.

**Not built:** conversation memory, Langfuse tracing, a Playwright test, the Elasticsearch down fallback, a CI eval gate, a public deployment. See `docs/backlog.md`.
